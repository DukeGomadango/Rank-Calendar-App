# アプリ概要（Overview）

## 製品名・コンセプト

- **アプリ名**: IRIAM rank planner（IRIAM ランク管理ツール）
- **コンセプト**: IRIAM ライバー向けの**非公式**ランク管理ツール。デイリーランクの目標・実績・ボーダー・スキップパスを日別に記録し、カレンダーとデータ表で一元管理する。

---

## 目的（解決したいこと）

- ライバーが「今週あとどれだけ + が必要か」「週の + 合計でランクアップの目安はどうか」を一目で把握できるようにする。
- +2 / +4 / +6 のボーダー、アンスコ、スキップパス使用日を日別に記録し、IRIAM のイベントスケジュールや目標+と一緒に管理する。
- 必要に応じてリスナーへスケジュールを安全に共有し、ロールごとに「何を見せるか」を権限で制御する。

---

## 対象ユーザー

| ユーザー種別 | 説明 |
|-------------|------|
| **ライバー（オーナー）** | IRIAM で配信するライバー。自分のカレンダーを所有し、スケジュール・ランクデータの登録・編集ができる。共有設定やイベント管理も行う。 |
| **リスナー（共有先）** | 招待リンクでカレンダーに参加したユーザー。オーナーが付与した権限に応じて、カレンダー・データ表・ボーダー・メモ・目標実績・ランク・イベントの閲覧が可能。編集は不可。 |

---

## 位置づけ・免責

- **非公式**: 当サービスは IRIAM 運営会社とは一切関係のない、非公式のスケジュール管理ツールです。
- **用途**: IRIAM ライバーがデイリーランクや配信スケジュールを**自分で管理**するためのツールであり、公式のランキングやイベント情報の代替ではありません。

---

## 用語・ドメインの整理

| 用語 | 説明 |
|------|------|
| **デイリーランク** | IRIAM における日次のランキング・配信目標。本アプリでは「目標+」「実績+」で管理。 |
| **+（プラス）** | ランクに関連する数値。目標+・実績+として日別に記録する。 |
| **ボーダー** | +2 / +4 / +6 などの境界値。日付ごとに記録可能。 |
| **スキップパス** | 使用した日は集計から除外する想定。`skip_pass_used` フラグで管理。 |
| **週** | JST の月曜始まり（ISO 週）。週間の + 合計や「+18 でランクアップ」「+12 で中間目標」などの判定に利用。 |
| **カレンダー** | 1 ユーザーに 1 つ以上のカレンダー。スケジュール・イベント・共有はカレンダー単位。 |
| **ロール** | 共有時に「どの権限を付与するか」をまとめたもの。招待リンクに紐づく。 |

---

## 提供価値（一言で）

- **ライバー**: ランク管理に必要な情報を一箇所に集約し、週単位の進捗とランクアップ目安を把握できる。ライト/ダークテーマに対応。
- **リスナー**: 招待された範囲で、推しのスケジュールやランク状況を共有された形で閲覧できる。
